# MegaGate Adapters

Ecosystem-specific package managers.

## Available Adapters

- `web/`: npm/pnpm compatibility
- `game/`: Unity, Unreal, Bevy, Godot
- `ai/`: PyPI, conda, HuggingFace models
- `cloud/`: Pulumi, Terraform, CDK
- `iot/`: Embedded Rust, PlatformIO, Zephyr
