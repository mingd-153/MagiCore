# MegaGate Templates

Project scaffolding templates for `mg create-*` commands.

## Template Variables

- `{{name}}`: Project name
- `{{author}}`: Author name
- `{{version}}`: Initial version
- `{{description}}`: Project description
- `{{license}}`: License (default: MIT)
- `{{year}}`: Current year

Files with `.tmpl` extension are processed with Handlebars.
