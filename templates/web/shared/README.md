# Shared web scaffold fragments

## Purpose

Holds shared web scaffold material organized under `partials/`. The tracked content currently consists of documentation placeholders rather than complete template contracts or generated project files.

## Contents

- `partials/` — candidate reusable layers for a base scaffold, Rust-ready crates, and monorepo composition. The layer README files describe intended output; they do not prove those layers are currently publishable.

## Status

This README documents the current folder role and the limits evidenced by the checked-in tree. Re-check source, manifests, and tests before relying on a future change.
