# Reusable web partial layer notes

## Purpose

Documents intended partial scaffold layers that can be composed into web and monorepo projects. No child directory currently contains a `template.toml` publish contract in this checkout.

## Contents

- `base/` — project README and common web metadata.
- `frontend-rust-ready/` — optional Rust engine crate note for a frontend project.
- `monorepo-frontend-rust-ready/` — the same optional Rust boundary for a monorepo frontend.
- `monorepo/` — frontend, backend, and package-area notes.
- `monorepo-packages/` — shared workspace configuration note.

## Status

This README documents the current folder role and the limits evidenced by the checked-in tree. Re-check source, manifests, and tests before relying on a future change.
