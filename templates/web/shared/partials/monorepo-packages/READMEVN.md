# Placeholder partial packages dùng chung trong monorepo

## Chức năng

Dành vị trí cấu hình toàn workspace và metadata package cho web monorepo. `config.README.md` hiện là nội dung duy nhất được Git theo dõi trong placeholder này.

## Nội dung

- `sources/config.README.md` — mô tả lane cấu hình dùng chung dự kiến.
- Cây hiện tại chưa có hợp đồng template hoặc payload config được sinh.

## Trạng thái

README này mô tả vai trò thư mục và giới hạn có bằng chứng từ cây file hiện tại. Hãy kiểm tra lại source, manifest và test trước khi dựa vào thay đổi sau này.
