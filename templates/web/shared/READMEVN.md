# Các mảnh scaffold web dùng chung

## Chức năng

Chứa vật liệu scaffold web dùng chung, được tổ chức dưới `partials/`. Nội dung đang được Git theo dõi hiện là ghi chú placeholder, chưa phải hợp đồng template hoàn chỉnh hay file dự án được sinh.

## Nội dung

- `partials/` — các layer dự kiến dùng lại cho scaffold cơ bản, crate Rust-ready và cấu trúc monorepo. README của layer mô tả đầu ra dự kiến, không chứng minh layer hiện có thể publish.

## Trạng thái

README này mô tả vai trò thư mục và giới hạn có bằng chứng từ cây file hiện tại. Hãy kiểm tra lại source, manifest và test trước khi dựa vào thay đổi sau này.
