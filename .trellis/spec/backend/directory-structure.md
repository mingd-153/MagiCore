### Updated Layout
```
src/webapp-core/
├─ api/
├─ service/
├─ domain/
├─ repository/
├─ config/
├─ util/
├─ tests/
├─ app/
│   ├─ swift/
│   ├─ kotlin/
│   ├─ dart/
│   └─ ts/
├─ web/
│   └─ static/
└─ shared/
```

**Explanation**:
- `app/` chứa mã UI cho các nền tảng Swift, Kotlin, Dart, TypeScript.
- `web/static/` chứa tài nguyên tĩnh (HTML, CSS, hình ảnh, bundle JS).
- Các thư mục core (`api`, `service`, `domain`, `repository`, `config`, `util`, `tests`) vẫn ở cấp cao nhất, không phụ thuộc UI.
