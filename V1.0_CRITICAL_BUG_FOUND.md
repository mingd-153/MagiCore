- Error: `zsh: illegal hardware instruction` at linking stage
- Occurs AFTER all packages downloaded successfully

## Root Cause Analysis

### Symptoms
1. Crash occurs during "Linking packages" phase
2. Only happens with 1000+ packages
3. Works fine with <1000 packages
4. NOT a download issue (downloads complete successfully)
5. NOT a resolution issue (solver works)

### Likely Causes
1. **Stack overflow** in linking recursion
2. **Memory corruption** in symlink creation loop
3. **Signal handling** issue in progress bar with large counts
4. **CPU instruction** incompatibility (SSE/AVX) in tight loop

### Code Location to Investigate
- `core/crates/mgc-installer/src/linker.rs` (if exists)
- `core/crates/mgc-installer/src/lib.rs` linking logic
- Progress bar rendering during linking phase
- Parallel linking implementation (rayon threads?)
