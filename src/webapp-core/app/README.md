# Application Logic Folder

The `app/` directory holds the client‑side application code:

- The main entry point (e.g., `main.tsx` or `index.js`).
- Routing configuration.
- Core UI components and pages.
- State‑management setup (hooks, stores, context providers).

This is where the SPA (single‑page application) or multi‑page app logic lives, separate from static assets.
