# Current task slice

## Purpose

This folder holds a focused work plan and checklist/evidence for strict parsing of versioned lockfile documents, including unknown-field rejection and v4 digest/signature coverage.

## Contents

- `plan.md` — task goal, scope, acceptance criteria, and verification commands.
- `todo.md` — checklist, test evidence, and recorded limitations.

## Status and use

`plan.md` defines the slice and acceptance criteria; `todo.md` records completed items and verification evidence, including failures or incomplete global gates. Treat that evidence as a dated task record, not a claim that the whole workspace or release is green. Re-run the relevant checks against current source before relying on it.
